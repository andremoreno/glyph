## 2024-11-20 - [DOM Data Leak via Clipboard Fallback Error Handling]\n**Vulnerability:** A vulnerability was discovered where the `useCopyToClipboard` hook's fallback method (using `document.execCommand`) could leave the generated password inside an invisible textarea in the DOM if an exception occurred during the selection or copying process, exposing sensitive data to other scripts or dev tools. Additionally, when the auto-clear timeout triggered, it failed to use the fallback method to clear the clipboard if the modern API was unavailable, leaving the password in the system clipboard indefinitely.\n**Learning:** Always use `try...finally` blocks when temporarily injecting sensitive data into the DOM for clipboard operations. Furthermore, ensure fallback mechanisms are consistently used for both setting and clearing sensitive data.\n**Prevention:** Create reusable wrapper functions that handle both modern APIs and fallbacks safely, ensuring temporary DOM elements are guaranteed to be cleaned up, and use this wrapper for all data handling operations (copying and clearing).
